# email-mcp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go MCP server exposing a single `send-email` tool that lets multica agents send email via local-smtp-forwarder.

**Architecture:** Stateless streamable-HTTP MCP server (JSON responses) with Bearer auth middleware. The tool handler reads multica identity directly from `req.Extra.Header` (the SDK populates this from the HTTP request in stateless mode — verified against go-sdk v1.8.0). Mail is submitted as plaintext SMTP to the forwarder on localhost. Spec: `docs/superpowers/specs/2026-11-04-email-mcp-design.md`.

**Tech Stack:** Go 1.26, `github.com/modelcontextprotocol/go-sdk` v1.8.0 (`mcp` package), `github.com/google/jsonschema-go` (SDK dep, used for input schema inference), `gopkg.in/yaml.v3`, stdlib `net/smtp`.

**SDK facts (verified by compiling and running a probe against go-sdk v1.8.0):**

- `mcp.NewServer(&mcp.Implementation{Name: "email-mcp", Version: "..."}, nil)` creates the server; `mcp.AddTool(server, &mcp.Tool{Name, InputSchema}, handler)` registers a typed tool with auto validation.
- Tool handler signature: `func(ctx context.Context, req *mcp.CallToolRequest, in In) (*mcp.CallToolResult, Out, error)`. Return `(&mcp.CallToolResult{Content: []mcp.Content{&mcp.TextContent{Text: jsonStr}}}, nil, nil)` to return JSON text. A non-nil `error` return becomes a JSON-RPC protocol error — for tool-level failures (bad params, send failure) return the error inside the JSON payload with a `*CallToolResult` whose `IsError` is set, not as a Go error.
- `req.Extra.Header` is an `http.Header` populated from the HTTP request for **both** stateful and stateless POSTs. This is how the tool reads `X-Multica-*`.
- `mcp.NewStreamableHTTPHandler(func(r *http.Request) *mcp.Server { return server }, &mcp.StreamableHTTPOptions{Stateless: true, JSONResponse: true})` returns an `http.Handler`.
- Client POSTs must carry `Content-Type: application/json` and `Accept: application/json, text/event-stream` (the handler 4xx's otherwise).

**Conventions:** Module path `email-mcp` (matches forwarder's unadorned module style, e.g. `local-smtp-forwarder`). Package `main` in repo root, one file per concern — same layout as local-smtp-forwarder. Tests are `_test.go` files next to the code. Commit after every green step.

```go
package main

import (
	"fmt"
	"net"
	"os"
	"strconv"

	"gopkg.in/yaml.v3"
)

// SMTPConfig points at the local-smtp-forwarder (or any plaintext SMTP
// submission endpoint) and names the envelope/From address.
type SMTPConfig struct {
	Host string
	Port int
	From string
}

func (s SMTPConfig) Addr() string {
	return net.JoinHostPort(s.Host, strconv.Itoa(s.Port))
}

type fileConfig struct {
	SMTP struct {
		Host string `yaml:"host"`
		Port int    `yaml:"port"`
		From string `yaml:"from"`
	} `yaml:"smtp"`
	MaxAttachmentMB int `yaml:"max_attachment_mb"`
}

type Config struct {
	SMTP            SMTPConfig
	MaxAttachmentMB int
}

// LoadConfig reads a YAML config file, applies defaults, then env overrides:
// SMTP_HOST / SMTP_PORT / SMTP_FROM / MAX_ATTACHMENT_MB. An empty path means
// "config.yaml in the current directory" (missing file is not an error when
// env vars provide everything).
func LoadConfig(path string) (*Config, error) {
	if path == "" {
		path = "config.yaml"
	}
	var fc fileConfig
	if data, err := os.ReadFile(path); err == nil {
		if err := yaml.Unmarshal(data, &fc); err != nil {
			return nil, fmt.Errorf("parse %s: %w", path, err)
		}
	} else if !os.IsNotExist(err) {
		return nil, fmt.Errorf("read %s: %w", path, err)
	}

	cfg := &Config{
		SMTP: SMTPConfig{
			Host: fc.SMTP.Host,
			Port: fc.SMTP.Port,
			From: fc.SMTP.From,
		},
		MaxAttachmentMB: fc.MaxAttachmentMB,
	}

	if cfg.SMTP.Host == "" {
		cfg.SMTP.Host = "127.0.0.1"
	}
	if cfg.SMTP.Port == 0 {
		cfg.SMTP.Port = 2525
	}
	if cfg.MaxAttachmentMB == 0 {
		cfg.MaxAttachmentMB = 10
	}

	// Env overrides.
	if v := os.Getenv("SMTP_HOST"); v != "" {
		cfg.SMTP.Host = v
	}
	if v := os.Getenv("SMTP_PORT"); v != "" {
		p, err := strconv.Atoi(v)
		if err != nil {
			return nil, fmt.Errorf("SMTP_PORT: %w", err)
		}
		cfg.SMTP.Port = p
	}
	if v := os.Getenv("SMTP_FROM"); v != "" {
		cfg.SMTP.From = v
	}
	if v := os.Getenv("MAX_ATTACHMENT_MB"); v != "" {
		n, err := strconv.Atoi(v)
		if err != nil {
			return nil, fmt.Errorf("MAX_ATTACHMENT_MB: %w", err)
		}
		cfg.MaxAttachmentMB = n
	}

	if cfg.SMTP.From == "" {
		return nil, fmt.Errorf("smtp.from (or SMTP_FROM) is required: the envelope sender address")
	}
	return cfg, nil
}
```

```go
package main

import (
	"crypto/rand"
	"encoding/base64"
	"fmt"
	"regexp"
	"strings"
	"time"
)

// Email is a fully-resolved message ready to be rendered.
type Email struct {
	From        string
	To          []string
	Cc          []string
	ReplyTo     string // empty = no Reply-To header
	Subject     string
	Body        string
	BodyType    string // "text" | "html"
	Attachments []Attachment
}

type Attachment struct {
	Filename    string
	Content     []byte
	ContentType string // guessed by extension when empty
}

// contentTypeByExt maps common extensions; unknown extensions get
// application/octet-stream.
func contentTypeByExt(name string) string {
	switch {
	case strings.HasSuffix(name, ".csv"):
		return "text/csv"
	case strings.HasSuffix(name, ".txt"):
		return "text/plain"
	case strings.HasSuffix(name, ".html"), strings.HasSuffix(name, ".htm"):
		return "text/html"
	case strings.HasSuffix(name, ".json"):
		return "application/json"
	case strings.HasSuffix(name, ".pdf"):
		return "application/pdf"
	case strings.HasSuffix(name, ".png"):
		return "image/png"
	case strings.HasSuffix(name, ".jpg"), strings.HasSuffix(name, ".jpeg"):
		return "image/jpeg"
	case strings.HasSuffix(name, ".xlsx"):
		return "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
	default:
		return "application/octet-stream"
	}
}

var nonASCII = regexp.MustCompile(`[^\x20-\x7E]`)

// encodeRFC2047 encodes s as an RFC 2047 B-encoded word when it contains
// non-ASCII bytes, otherwise returns it unchanged.
func encodeRFC2047(s string) string {
	if !nonASCII.MatchString(s) {
		return s
	}
	return "=?utf-8?B?" + base64.StdEncoding.EncodeToString([]byte(s)) + "?="
}

// foldHeader inserts CRLF+space soft breaks so no header line exceeds 998
// bytes (RFC 5322 line-length limit). Only safe for unstructured values.
func foldHeader(line string) string {
	const limit = 900
	if len(line) <= limit {
		return line
	}
	var b strings.Builder
	for len(line) > limit {
		cut := strings.LastIndexAny(line[:limit], " \t")
		if cut <= 0 {
			cut = limit
		}
		b.WriteString(line[:cut])
		b.WriteString("\r\n ")
		line = strings.TrimSpace(line[cut:])
	}
	b.WriteString(line)
	return b.String()
}

// wrapBase64 splits data into 76-char base64 lines (RFC 2045 §6.8).
func wrapBase64(data []byte) string {
	enc := base64.StdEncoding.EncodeToString(data)
	var b strings.Builder
	for len(enc) > 76 {
		b.WriteString(enc[:76])
		b.WriteString("\r\n")
		enc = enc[76:]
	}
	b.WriteString(enc)
	return b.String()
}

// normalizeCRLF converts bare LF to CRLF and strips stray CR.
func normalizeCRLF(s string) string {
	s = strings.ReplaceAll(s, "\r\n", "\n")
	s = strings.ReplaceAll(s, "\r", "\n")
	return strings.ReplaceAll(s, "\n", "\r\n")
}

// wrapBody folds body lines longer than 998 chars.
func wrapBody(s string) string {
	lines := strings.Split(s, "\r\n")
	for i, line := range lines {
		if len(line) > 998 {
			lines[i] = foldHeader(line)
		}
	}
	return strings.Join(lines, "\r\n")
}

// newBoundary generates a random multipart boundary.
func newBoundary() string {
	var b [16]byte
	if _, err := rand.Read(b[:]); err != nil {
		return fmt.Sprintf("boundary-%d", time.Now().UnixNano())
	}
	return "=_multipart_" + strings.ToLower(base64.RawURLEncoding.EncodeToString(b[:]))
}

// newMessageID builds <random@domain-of-from>.
func newMessageID(from string) string {
	var b [12]byte
	if _, err := rand.Read(b[:]); err != nil {
		return fmt.Sprintf("<%d.fallback@%s>", time.Now().UnixNano(), domainOf(from))
	}
	domain := domainOf(from)
	if domain == "" {
		domain = "email-mcp.invalid"
	}
	return fmt.Sprintf("<%s@%s>", strings.ToLower(base64.RawURLEncoding.EncodeToString(b[:])), domain)
}

// domainOf returns the part after the last '@'.
func domainOf(addr string) string {
	if i := strings.LastIndex(addr, "@"); i >= 0 && i < len(addr)-1 {
		return addr[i+1:]
	}
	return ""
}

// BuildMessage renders Email as full RFC 5322 bytes (CRLF endings).
func BuildMessage(e Email) ([]byte, error) {
	if e.BodyType != "text" && e.BodyType != "html" {
		return nil, fmt.Errorf("body_type must be \"text\" or \"html\", got %q", e.BodyType)
	}

	var h strings.Builder
	h.WriteString("From: " + e.From + "\r\n")
	h.WriteString("To: " + strings.Join(e.To, ", ") + "\r\n")
	if len(e.Cc) > 0 {
		h.WriteString("Cc: " + strings.Join(e.Cc, ", ") + "\r\n")
	}
	if e.ReplyTo != "" {
		h.WriteString("Reply-To: " + e.ReplyTo + "\r\n")
	}
	h.WriteString("Subject: " + foldHeader(encodeRFC2047(e.Subject)) + "\r\n")
	h.WriteString("Date: " + time.Now().Format(time.RFC1123Z) + "\r\n")
	h.WriteString("Message-ID: " + newMessageID(e.From) + "\r\n")
	h.WriteString("MIME-Version: 1.0\r\n")

	textCT := "text/plain; charset=UTF-8"
	if e.BodyType == "html" {
		textCT = "text/html; charset=UTF-8"
	}
	body := wrapBody(normalizeCRLF(e.Body))

	var out strings.Builder
	if len(e.Attachments) == 0 {
		out.WriteString(h.String())
		out.WriteString("Content-Type: " + textCT + "\r\n")
		out.WriteString("Content-Transfer-Encoding: 8bit\r\n")
		out.WriteString("\r\n")
		out.WriteString(body)
		return []byte(out.String()), nil
	}

	boundary := newBoundary()
	out.WriteString(h.String())
	out.WriteString("Content-Type: multipart/mixed; boundary=\"" + boundary + "\"\r\n")
	out.WriteString("\r\n")
	out.WriteString("This is a multipart message in MIME format.\r\n")

	// Text part.
	out.WriteString("--" + boundary + "\r\n")
	out.WriteString("Content-Type: " + textCT + "\r\n")
	out.WriteString("Content-Transfer-Encoding: 8bit\r\n")
	out.WriteString("\r\n")
	out.WriteString(body)
	out.WriteString("\r\n")

	// Attachment parts.
	for _, a := range e.Attachments {
		ct := a.ContentType
		if ct == "" {
			ct = contentTypeByExt(a.Filename)
		}
		out.WriteString("--" + boundary + "\r\n")
		out.WriteString("Content-Type: " + ct + "\r\n")
		out.WriteString("Content-Transfer-Encoding: base64\r\n")
		out.WriteString("Content-Disposition: attachment; filename=\"" + a.Filename + "\"\r\n")
		out.WriteString("\r\n")
		out.WriteString(wrapBase64(a.Content))
		out.WriteString("\r\n")
	}
	out.WriteString("--" + boundary + "--\r\n")
	return []byte(out.String()), nil
}
```

```go
				line = line[1:]

			data.WriteString("\n")
			continue
		}

		case strings.HasPrefix(upper, "EHLO"), strings.HasPrefix(upper, "HELO"):
```

```go
package main

import (
	"fmt"
	"net"
	"net/smtp"
	"strconv"
	"time"
)

// SMTPSender submits mail to a plaintext SMTP endpoint (local-smtp-forwarder).
// No TLS, no AUTH: it trusts the network to be loopback.
type SMTPSender struct {
	Host string
	Port int
}

// Send performs one SMTP transaction: EHLO, MAIL FROM, RCPT TO (each
// recipient), DATA, QUIT. Errors are wrapped with the stage that failed.
func (s *SMTPSender) Send(from string, to []string, msg []byte) error {
	addr := net.JoinHostPort(s.Host, strconv.Itoa(s.Port))
	conn, err := net.DialTimeout("tcp", addr, 10*time.Second)
	if err != nil {
		return fmt.Errorf("dial smtp %s: %w", addr, err)
	}
	if err := conn.SetDeadline(time.Now().Add(30 * time.Second)); err != nil {
		conn.Close()
		return fmt.Errorf("set deadline: %w", err)
	}
	c, err := smtp.NewClient(conn, s.Host)
	if err != nil {
		conn.Close()
		return fmt.Errorf("smtp client: %w", err)
	}
	defer c.Close()

	if err := c.Hello("email-mcp"); err != nil {
		return fmt.Errorf("ehlo: %w", err)
	}
	if err := c.Mail(from); err != nil {
		return fmt.Errorf("MAIL FROM: %w", err)
	}
	for _, rcpt := range to {
		if err := c.Rcpt(rcpt); err != nil {
			return fmt.Errorf("RCPT TO <%s>: %w", rcpt, err)
		}
	}
	w, err := c.Data()
	if err != nil {
		return fmt.Errorf("DATA: %w", err)
	}
	if _, err := w.Write(msg); err != nil {
		return fmt.Errorf("write message: %w", err)
	}
	if err := w.Close(); err != nil {
		return fmt.Errorf("finish DATA: %w", err)
	}
	return c.Quit()
}
```

```go
package main

import "net/http"

// multicaHeaderToField mirrors the header set injected by
// multica-stdio-mcp-proxy (proxy.go forwardMessage) and consumed by
// bigdata-mcp-pg's AuthKeyMiddleware.
var multicaHeaderToField = map[string]string{
	"X-Multica-Workspace-Id": "workspace_id",
	"X-Multica-Agent-Id":     "agent_id",
	"X-Multica-Task-Id":      "task_id",
	"X-Multica-User-Id":      "user_id",
	"X-Multica-User-Name":    "user_name",
	"X-Multica-User-Email":   "user_email",
}

// MulticaContextFromHeaders collects the X-Multica-* identity headers into
// the multica_context object echoed in tool results. Absent or empty values
// are omitted; a nil header yields an empty map (local dev).
func MulticaContextFromHeaders(h http.Header) map[string]string {
	ctx := map[string]string{}
	if h == nil {
		return ctx
	}
	for header, field := range multicaHeaderToField {
		if v := h.Get(header); v != "" {
			ctx[field] = v
		}
	}
	return ctx
}
```

```go
// validEmail is a loose address check: exactly one '@', non-empty local and
// domain parts. Full RFC 5322 validation is out of scope for an MCP tool.
func validEmail(s string) bool {
	at := strings.Count(s, "@")
	if at != 1 {
		return false
	}
	i := strings.Index(s, "@")
	return i > 0 && i < len(s)-1 && !strings.ContainsAny(s, " \t\r\n")
}

// normalizeRecipients converts a to/cc argument that may be a string or an
// array of strings into []string, trimming whitespace and dropping empties.
func normalizeRecipients(v any) ([]string, error) {
	switch x := v.(type) {
	case nil:
		return nil, nil
	case string:
		s := strings.TrimSpace(x)
		if s == "" {
			return nil, nil
		}
		return []string{s}, nil
	case []any:
		var out []string
		for _, item := range x {
			s, ok := item.(string)
			if !ok {
				return nil, fmt.Errorf("recipient list must contain only strings, got %T", item)
			}
			s = strings.TrimSpace(s)
			if s != "" {
				out = append(out, s)
			}
		}
		return out, nil
	default:
		return nil, fmt.Errorf("recipient argument must be a string or array of strings, got %T", v)
	}
}

// SendEmail contains the tool logic, separated from the MCP wiring so it is
// directly testable. hdr is the HTTP request header carrying X-Multica-*.
// It returns the JSON payload bytes (never a protocol-level error).
func (env *ServerEnv) SendEmail(hdr http.Header, args map[string]any) ([]byte, error) {
	mc := MulticaContextFromHeaders(hdr)
	start := time.Now()

	fail := func(format string, a ...any) ([]byte, error) {
		return errPayload(fmt.Sprintf(format, a...), mc), nil
	}

	// --- normalize arguments -------------------------------------------------
	subject, _ := args["subject"].(string)
	if strings.TrimSpace(subject) == "" {
		return fail("parameter \"subject\" is required")
	}
	body, _ := args["body"].(string)
	if body == "" {
		return fail("parameter \"body\" is required")
	}
	bodyType, _ := args["body_type"].(string)
	if bodyType == "" {
		bodyType = "text"
	}
	if bodyType != "text" && bodyType != "html" {
		return fail("parameter \"body_type\" must be \"text\" or \"html\", got %q", bodyType)
	}

	to, err := normalizeRecipients(args["to"])
	if err != nil {
		return fail("parameter \"to\": %v", err)
	}
	cc, err := normalizeRecipients(args["cc"])
	if err != nil {
		return fail("parameter \"cc\": %v", err)
	}

	// --- recipient fallback --------------------------------------------------
	userEmail := mc["user_email"]
	replyTo := ""
	if len(to) == 0 {
		if userEmail == "" {
			return fail("no recipient: parameter \"to\" is empty and multica header user_email is absent — provide \"to\" or call from a multica task with a resolvable user email")
		}
		to = []string{userEmail}
		replyTo = userEmail
	}

	for _, addr := range append(append([]string{}, to...), cc...) {
		if !validEmail(addr) {
			return fail("invalid email address %q", addr)
		}
	}

	// --- attachments ---------------------------------------------------------
	var attachments []Attachment
	if rawList, ok := args["attachments"].([]any); ok {
		for i, raw := range rawList {
			m, ok := raw.(map[string]any)
			if !ok {
				return fail("attachments[%d] must be an object", i)
			}
			filename, _ := m["filename"].(string)
			if strings.TrimSpace(filename) == "" {
				return fail("attachments[%d].filename is required", i)
			}
			b64, _ := m["content_b64"].(string)
			content, err := base64.StdEncoding.DecodeString(b64)
			if err != nil {
				return fail("attachments[%d].content_b64 is not valid base64: %v", i, err)
			}
			limitBytes := int64(env.Config.MaxAttachmentMB) * 1024 * 1024
			if int64(len(content)) > limitBytes {
				return fail("attachment %q is %d bytes, exceeding the %d MiB limit", filename, len(content), env.Config.MaxAttachmentMB)
			}
			ct, _ := m["content_type"].(string)
			attachments = append(attachments, Attachment{
				Filename:    filename,
				Content:     content,
				ContentType: ct,
			})
		}
	}

	// --- build & send ---------------------------------------------------------
	email := Email{
		From:        env.Config.SMTP.From,
		To:          to,
		Cc:          cc,
		ReplyTo:     replyTo,
		Subject:     subject,
		Body:        body,
		BodyType:    bodyType,
		Attachments: attachments,
	}
	msg, err := BuildMessage(email)
	if err != nil {
		return fail("build message: %v", err)
	}

	messageID := headerValueOf(string(msg), "Message-ID")

	if err := env.Sender.Send(env.Config.SMTP.From, envelopeRecipients(to, cc), msg); err != nil {
		return fail("smtp send failed: %v", err)
	}

	result := emailResult{
		Success:         true,
		MessageID:       messageID,
		To:              to,
		Cc:              cc,
		From:            env.Config.SMTP.From,
		ReplyTo:         replyTo,
		AttachmentCount: len(attachments),
		DurationMs:      float64(time.Since(start).Microseconds()) / 1000.0,
		MulticaContext:  mc,
	}
	raw, err := json.Marshal(result)
	if err != nil {
		return errPayload("marshal result: "+err.Error(), mc), nil
	}
	return raw, nil
}

// envelopeRecipients concatenates to + cc for RCPT TO.
func envelopeRecipients(to, cc []string) []string {
	out := make([]string, 0, len(to)+len(cc))
	out = append(out, to...)
	out = append(out, cc...)
	return out
}
```

```go
import (
```

```go
// bearerAuth validates Authorization: Bearer <key> against a comma-separated
// key set. An empty key set disables auth (local dev). /health is exempt.
func bearerAuth(keys string, next http.Handler) http.Handler {
	allowed := map[string]bool{}
	for _, k := range strings.Split(keys, ",") {
		if k = strings.TrimSpace(k); k != "" {
			allowed[k] = true
		}
	}
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if len(allowed) == 0 || r.URL.Path == "/health" {
			next.ServeHTTP(w, r)
			return
		}
		h := r.Header.Get("Authorization")
		const prefix = "Bearer "
		if !strings.HasPrefix(h, prefix) || !allowed[strings.TrimSpace(h[len(prefix):])] {
			w.Header().Set("Content-Type", "application/json")
			w.WriteHeader(http.StatusUnauthorized)
			_ = json.NewEncoder(w).Encode(map[string]string{
				"error":   "unauthorized",
				"message": "Invalid or missing authentication key",
			})
			return
		}
		next.ServeHTTP(w, r)
	})
}
```

```go
// NewHandler builds the full HTTP handler: /health + /mcp (stateless,
// JSON-response streamable transport) behind bearer auth.
func NewHandler(env *ServerEnv, authKeys string) http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		_, _ = w.Write([]byte(`{"status":"ok"}`))
	})

	server := mcp.NewServer(&mcp.Implementation{Name: "email-mcp", Version: "v0.0.1"}, nil)
	mcp.AddTool(server, &mcp.Tool{
		Name:        "send-email",
		Description: "Send an email via the configured SMTP relay. If \"to\" is empty, the multica caller's user email is used; if that is also absent the call fails.",
	}, func(ctx context.Context, req *mcp.CallToolRequest, in struct{}) (*mcp.CallToolResult, struct{}, error) {
		// Normalize raw arguments (to/cc may be string or array).
		var args map[string]any
		if len(req.Params.Arguments) > 0 {
			if err := json.Unmarshal(req.Params.Arguments, &args); err != nil {
				return &mcp.CallToolResult{IsError: true, Content: []mcp.Content{&mcp.TextContent{Text: `{"success":false,"error":"invalid arguments: ` + err.Error() + `"}`}}}, struct{}{}, nil
			}
		}
		var hdr map[string][]string
		if req.Extra != nil && req.Extra.Header != nil {
			hdr = req.Extra.Header
		}
		payload, err := env.SendEmail(hdr, args)
		if err != nil {
			return nil, struct{}{}, err
		}
		isErr := !jsonPayloadSuccess(payload)
		return &mcp.CallToolResult{
			IsError: isErr,
			Content: []mcp.Content{&mcp.TextContent{Text: string(payload)}},
		}, struct{}{}, nil
	})

	mux.Handle("/mcp", mcp.NewStreamableHTTPHandler(
		func(r *http.Request) *mcp.Server { return server },
		&mcp.StreamableHTTPOptions{Stateless: true, JSONResponse: true},
	))

	return bearerAuth(authKeys, mux)
}

// jsonPayloadSuccess reports whether the tool's JSON payload says success.
func jsonPayloadSuccess(payload []byte) bool {
	var probe struct {
		Success bool `json:"success"`
	}
	return json.Unmarshal(payload, &probe) == nil && probe.Success
}
```

- [ ] **Step 5: README.md**

`README.md`:

````markdown
# email-mcp

MCP Server for sending email from multica agents. One tool: `send-email`.

```
multica agent → multica-stdio-mcp-proxy → email-mcp :8000/mcp → local-smtp-forwarder :2525 → upstream SMTP
```

- Streamable HTTP transport (stateless, JSON responses), Bearer auth
- Recipient fallback: empty `to` → `X-Multica-User-Email` → error
- From is fixed (`smtp.from`); on fallback a `Reply-To` points at the caller
- `X-Multica-*` headers are echoed in the tool result as `multica_context`

## Install

Download a self-contained binary from [Releases](https://github.com/courage-zen/bigdata-mcp-email/releases):

```sh
tar -xzf email-mcp-linux-arm64.tar.gz   # or email-mcp-linux-amd64.tar.gz
MCP_AUTH_KEY=your-key ./email-mcp
```

Or run from source:

```bash
make build
cp config.example.yaml config.yaml   # edit smtp.from
make run
make test
```

## Configure

`config.yaml` (path override: `EMAIL_MCP_CONFIG`):

```yaml
smtp:
  host: "127.0.0.1"     # local-smtp-forwarder
  port: 2525
  from: "noreply@example.com"
max_attachment_mb: 10   # optional
```

Environment variables override the file: `SMTP_HOST` `SMTP_PORT` `SMTP_FROM`
`MAX_ATTACHMENT_MB`. Server env: `MCP_AUTH_KEY` (comma-separated bearer keys;
unset = no auth), `MCP_HOST` (default 0.0.0.0), `MCP_PORT` (default 8000).
`/health` is exempt from auth.

## Multica wiring

Configure the agent's mcp_config through multica-stdio-mcp-proxy:

```json
{
  "mcpServers": {
    "email-mcp": {
      "command": "multica-stdio-mcp-proxy",
      "args": [
        "--url", "http://your-email-mcp-host:8000/mcp",
        "--token", "<upstream-bearer-key>",
        "--allow-http"
      ]
    }
  }
}
```

The proxy injects the `X-Multica-*` identity headers automatically.

## send-email tool

| argument | type | notes |
|----------|------|-------|
| `to` | string \| string[] | empty → multica user email |
| `cc` | string \| string[] | optional |
| `subject` | string | required |
| `body` | string | required |
| `body_type` | "text" \| "html" | default "text" |
| `attachments` | array | `{filename, content_b64, content_type?}` |

Returns JSON: `success`, `message_id`, `to`, `cc`, `from`, `reply_to`,
`attachment_count`, `duration_ms`, `multica_context`.

## Deployment (k8s sidecar)

Run email-mcp and [local-smtp-forwarder](https://github.com/courage-zen/local-smtp-forwarder)
as two containers in one pod: email-mcp exposes 8000, the forwarder listens on
2525 pod-locally and holds the upstream SMTP credentials. The dependency
between the two is the SMTP protocol itself — point `smtp.host`/`smtp.port`
at any plaintext submission endpoint.
````
